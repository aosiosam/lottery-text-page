# 开奖文字页

手机适配的白底文字页面，支持后台设置开奖后的文字。

## 启动

安装 Node.js 22 或更新版本，在项目目录运行：

```sh
node server.mjs
```

前台：`http://localhost:3000`，后台：`http://localhost:3000/admin`。

首次运行生成的后台密码保存在 `data/admin-password.txt`。也可用环境变量 `ADMIN_PASSWORD` 设置密码，`PORT` 设置端口（默认 3000）。

## 显示规则

- 开奖前持续显示加载动画，后台只设置开奖后文字。
- 读取 49208.com 的澳彩接口，核实北京时间当天七个号码均已开出后，显示开奖后文字。
- 跨天恢复加载动画；接口异常时继续加载。
- 文字左对齐、保留换行，前台每 10 秒更新。

设置与管理密码在 `data/` 保存，已排除在版本管理之外。

## 部署

需要支持 Node.js 的服务器与持久化文件目录。通过 HTTPS 提供公网访问。GitHub Pages 仅支持静态页面，不能运行本项目的后台。

## 每日历史

开奖完成后自动按北京时间日期保存一份文字和号码快照，日期页面如 `/2026-11-12`。后台可查看历史记录。历史快照不随之后的文字修改而变化。记录从启用日开始，不补造往期数据。

线上版本位于 `online/`，使用托管持久化存储；线上每天北京时间 23:55 另有云端自动归档检查，本地版本在前台访问时归档。

## 隐藏二维码图片

后台点击“生成隐藏二维码图片”。通过草料公开接口生成网址二维码；上传底图后，采用用户确认的透明白底补偿算法生成 PNG，可保存设置、下载原图，直接下载带日期的 PNG 原文件。定位框只用于编辑，不写入图片。需保留 PNG，传输压缩可能影响识别。已有苹果微信样图实测成功，其他底图与安卓仍需实测。

## 当前生产部署

生产网站 https://svitla.it.com ，后台 /admin，隐藏图生成 /poster。Windows 独立目录 C:\Sites\svitla-text，Node 仅监听 127.0.0.1:3088，由独立 IIS 应用池代理。部署参考 deployment/windows/README.md。现有站点不参与部署。

## 当前显示控制与浏览器测试入口

当前生产服务不再以49图库开奖状态作为显示条件。后台选择手动开关，或每天按北京时间 HH:mm 开启；定时模式跨天重新等待。首次公开显示保存当天历史快照。后台使用 admin 账号，密码存于私有 data 目录，不提交仓库。

二维码通过草料编码本站 /open-browser?target= 入口；安卓微信返回附件响应供实测，苹果显示手动打开浏览器指引，普通浏览器302跳转。能否触发微信提示依赖客户端，已拦截的入口无法执行此逻辑。online/ 是旧托管平台备份，当前生产以根目录 Node 服务为准。
