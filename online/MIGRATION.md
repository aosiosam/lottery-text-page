# Windows migration

The production handlers in windows-server.mjs are adapted to a serverless Worker by build-migration.mjs. Run node build-migration.mjs and node check-migration.mjs before publication.

Private state is stored in R2 under windows-migration-v2/. ADMIN_PASSWORD must be set as a hosted secret. Passwords, server keys, raw backups and customer data must never be committed unencrypted.

Preserved behavior: Beijing calendar dates; manual/scheduled visibility; one-second no-cache display; historical snapshots and edits/deletions; transparent QR composition; Android attachment prompt; primary eharmony.me with svitla.it.com fallback.

Keep Windows serving both domains until the hosted backend, imported data, HTTPS, mobile access and existing dated QR links pass verification. Remove only the isolated lottery project after cutover; never touch C:\49 or other IIS projects.
